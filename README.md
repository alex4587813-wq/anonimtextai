# Локальный анонимизатор

Лёгкое локальное приложение для macOS и Windows, которое заменяет
чувствительные данные псевдонимами перед передачей текста во внешние
ИИ-сервисы.

## Возможности MVP

- ФИО: `[PERSON_001]`
- организации: `[COMPANY_001]`
- телефоны: `[PHONE_001]`
- email: `[EMAIL_001]`
- IPv4-адреса: `[IP_ADDRESS_001]`
- реквизиты и адреса: `[REQUISITE_001]`
- одинаковые значения получают одинаковые псевдонимы;
- категории обезличивания можно включать и отключать;
- слова и фразы можно добавлять в сохраняемый список исключений;
- организации можно добавлять в список обязательной замены;
- по умолчанию обязательно заменяются `СИЛА`, `Платформикс` и `Базовые решения`;
- структура абзацев и переносы строк сохраняются;
- результат можно отредактировать вручную;
- обработка выполняется локально, без сети и платных сервисов.

Распознавание использует регулярные выражения и лёгкие эвристики для русских
ФИО. Версия macOS также использует встроенный системный фреймворк Apple
NaturalLanguage. Отдельные модели не загружаются.

## Системные требования

- macOS 13 или новее — для версии macOS;
- Windows 10 или Windows 11 с Windows PowerShell 5.1 — для тестовой
  Windows-версии;
- Swift 6 требуется только для сборки macOS из исходников;
- полный Xcode не требуется.

## Запуск тестов

```bash
./scripts/test.sh
```

## Сборка приложения

```bash
./scripts/build-app.sh
```

Готовое приложение появится в:

```text
dist/Локальный анонимизатор.app
```

## Сборка установочного DMG

```bash
./scripts/build-dmg.sh
```

Результат:

```text
dist/Локальный анонимизатор-1.0.0-macOS.dmg
```

## Сборка комплекта для Windows

```bash
./scripts/build-windows-package.sh
```

Результат:

```text
dist/LocalAnonymizer-Windows-1.0.0.zip
```

После распаковки Windows-версия запускается через `Start.bat`. Для проверки
алгоритма предусмотрен `RunTests.bat`.

## Ограничения

Автоматическое распознавание может пропустить нестандартное ФИО или ошибочно
принять обычный текст за чувствительные данные. Результат необходимо проверить
перед передачей во внешний сервис.

Приложение не сохраняет историю. В консольных логах фиксируются только
технические события, длина текста и количество найденных фрагментов — без
содержимого исходного или обезличенного текста.
