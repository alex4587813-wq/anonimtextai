# Правила обезличивания

Документ описывает поведение версии 1.0.2 для macOS и Windows.

## Порядок работы

1. Приложение ищет включённые категории чувствительных данных.
2. Совпадения из «Списка исключений» удаляются из результатов автоматического
   поиска.
3. Применяются правила из блока «Замена слов».
4. Пересекающиеся совпадения разрешаются по приоритету.
5. Принятые фрагменты заменяются нумерованными псевдонимами.

Одинаковые записи внутри одного запуска получают одинаковый псевдоним.

## ФИО

Поддерживаются русские записи с заглавной буквы:

- имя и фамилия: `Алексей Майборода`;
- фамилия и имя: `Майборода Алексей`;
- фамилия, имя и отчество;
- инициал перед фамилией: `А.Ковешников`, `А. Майборода`;
- один или два инициала после фамилии: `Ковешников А.`,
  `Майборода А.А.`;
- два инициала перед фамилией: `А.А. Майборода`.

Одно ФИО распознаётся только в пределах одной строки. Перенос строки считается
границей записи, поэтому соседние сотрудники не объединяются в один фрагмент.

Полная и сокращённая запись одного человека сравниваются как разные строки и
могут получить разные псевдонимы.

## Структурированные данные

Приложение заменяет:

- email — `[EMAIL_001]`;
- телефон — `[PHONE_001]`;
- IPv4 — `[IP_ADDRESS_001]`;
- ИНН, КПП, ОГРН, ОГРНИП, ОКПО, БИК, банковские счета, СНИЛС,
  паспортные данные и подписанные адреса — `[REQUISITE_001]`.

Email, телефон, IP и реквизит имеют приоритет над совпадением внутри них из
блока «Замена слов». Например, если в правила добавлено `platformix.ru`, адрес
`Dell-OPM-Request@platformix.ru` всё равно заменяется целиком на `[EMAIL_001]`.

## Список исключений

Слово или фраза из списка исключений оставляет автоматически найденный
фрагмент без изменения. Исключение применяется только к включённым категориям
автоматического поиска.

Правило из блока «Замена слов» имеет приоритет над исключением.

## Замена слов

Блок предназначен для внутренних названий, редких фамилий и других терминов,
которые нужно скрывать гарантированно. Совпадение заменяется меткой
`[COMPANY_XXX]` для совместимости с текущим форматом результата.

Поддерживаются:

- точное слово: `Платформикс`;
- фраза: `Базовые решения`;
- маска с одной звёздочкой в конце основы: `Иванов*`.

Маска `Иванов*` находит `Иванов`, `Иванову`, `Ивановым` и другие продолжения
той же основы. Звёздочка в начале или середине значения не поддерживается.
Правило не срабатывает внутри более длинного слова: `Иванов*` не заменит
`Псевдоиванов`.

По умолчанию добавлены `СИЛА`, `Платформикс` и `Базовые решения`.

## Приоритеты

От большего к меньшему:

1. включённые структурированные данные: email, IP, телефон и реквизиты;
2. правила «Замена слов»;
3. организации с явным контекстом и эвристики ФИО;
4. остальные результаты автоматического распознавания.

Если категория выключена, её автоматическое совпадение не участвует в
обработке. Правила «Замена слов» продолжают работать независимо от флажка
«Организации».

## Ограничения и контроль

Алгоритм работает локально, без внешних API и загружаемых моделей. Эвристики
могут пропустить нестандартную запись или принять обычную пару слов с заглавных
букв за ФИО. Перед передачей текста во внешний сервис результат необходимо
проверить вручную.
