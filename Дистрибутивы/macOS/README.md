# Скачать для macOS

Подходит для macOS 13 или новее на Mac с процессором Apple Silicon
(M1, M2, M3, M4 и новее).

## Файл

[Скачать LocalAnonymizer-macOS-1.0.2.dmg](https://github.com/alex4587813-wq/anonimtextai/releases/download/v1.0.2/LocalAnonymizer-macOS-1.0.2.dmg)

После скачивания:

1. Откройте DMG.
2. Перетащите «Локальный анонимизатор» в папку `Applications`.
3. При первом запуске нажмите на приложение правой кнопкой мыши, выберите
   «Открыть» и подтвердите запуск.
