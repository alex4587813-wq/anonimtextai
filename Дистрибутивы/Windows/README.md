# Скачать для Windows

Подходит для Windows 10 и Windows 11.

## Файл

[Скачать LocalAnonymizer-Windows-1.0.2.zip](https://github.com/alex4587813-wq/anonimtextai/releases/download/v1.0.2/LocalAnonymizer-Windows-1.0.2.zip)

После скачивания:

1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Запустите `Start.bat`.
3. Для самопроверки запустите `RunTests.bat`.

Не запускайте `Start.bat` непосредственно внутри ZIP-архива.
